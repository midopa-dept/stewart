# 평가기 해시

평가기 판(채점 코드·과제 정의·과제용 저장소)을 **결과를 보기 전에** sha256 으로 고정한 기록이다. 판이 바뀌면 해시가 바뀌고, 고정한 해시와 다른 판으로 낸 결과는 무효로 다룬다. 결과 줄(`summary.json` 의 `meta.eval_hash`)과 이 해시를 대 보면 어느 판으로 잰 결과인지 확인할 수 있다.

- 개발·봉인 규약: [`../protocol.md`](../protocol.md), 봉인 판정 기준: [`../registry/holdout-criteria.md`](../registry/holdout-criteria.md), 봉인 묶음 표: [`../registry/holdout-sets.tsv`](../registry/holdout-sets.tsv)
- 과제 정의 sha(실행 코드와 무관한 sha)를 내는 스크립트: [`../analysis/x1/task_sha.py`](../analysis/x1/task_sha.py)

## 파일 꼴

- 첫 줄은 그 판의 전체 해시다(`run_eval.py --hash` 가 내는 값). 일부 파일은 같은 줄 뒤나 `#` 머리 줄에 고정 시각·과제 수·구성·selftest 결과를 적었다.
- 개발 묶음(v1 계열·v2 계열·lc1.0)은 그 아래에 판 폴더 기준 상대 경로와 파일별 sha256 목록을 그대로 싣는다. 목록의 `repos` 아래 줄은 판 폴더 안의 과제용 저장소(직접 만든 연습 저장소) 파일이다.
- **봉인 묶음은 전체 해시·개수·구성·머리 설명만 싣고 파일별 목록은 싣지 않는다.** 파일 이름이 과제를 가리키기 때문이다. 해당 파일 끝에 "# 파일별 목록은 봉인 묶음이라 싣지 않음" 한 줄이 있다. 봉인 묶음의 과제 ID·과제 내용도 싣지 않는다.
- 머리의 사람·세션 표시는 역할 이름(평가 담당·연구 담당·총괄)으로, 판 폴더 경로는 판 이름으로 바꿨다. 해시·시각·개수·구성은 원본 그대로다.
