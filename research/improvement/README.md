# 개선 계획 — 탐구 보고서, 대조·차례, 파인튜닝·증류 조사

> 원래 기록: 사람(제품 주인)의 "stewart 개선 방향 탐구 보고서"(판 13, 2026-11-11), 그것을 코드·기록과 대조한 차례 제안(2026-11-11 저녁), 총괄 지시의 파인튜닝·증류 조사(2026-11-12). 셋 다 비공개 운영 기록이고, 파일마다 머리에 원래 기록과 바꾼 것을 따로 적었다.
> 꼴: **조사·계획(판정 없음)**. 이 폴더에는 측정 결과가 없다. 인용한 숫자는 남의 논문·문서이거나 다른 실험의 기록값이다.
> 실행 조건: 실행 없음. 다루는 모델 = Qwen 계열 27B 4비트(판 이름 가림 — 원본 판과 abliteration 판). 장비 이야기는 빌린 GPU(RTX 3090) 기준이다.

**맨 위 요약**
- 사람의 탐구 보고서는 stewart 의 빈 곳 여섯(본문 툴콜 파싱, 인자 JSON 복구, 편집 직후 되먹임, OpenAI 백엔드 재시도, 추론 되돌려 보내기, 공개 벤치 어댑터)과 평가 원칙(만든 쪽이 짠 벤치는 회귀용만, 봉인 세트 격리, 동료 실행기 기준선), 세 축(실행기 × 모델 × 과제) 격차 분해 방법론을 냈다([report.md](report.md)).
- 대조 결과 빈 곳 여섯은 그날 main(판 75)에도 그대로 비어 있었다. 차례는 "기록부터 세기 → 견고성 넷 → 공개 벤치 어댑터 + 동료 기준선 → 손잡이 실험 → 세 축 연구"로 제안했고, 추론 되돌려 보내기는 "바로 고칠 결함"이 아니라 "손잡이로 넣고 잴 것"으로 옮겼다([plan.md](plan.md)).
- 파인튜닝·증류 조사는 27B QLoRA 가 24GB 한 장에서 된다는 것, 증류 teacher 는 약관이 허용하는 것(DeepSeek 직접 API, MIT·Apache 공개 가중치, 27B 자신)만 쓴다는 것, 첫 실험은 "오르는가"가 아니라 "고리가 끝까지 돌고 되돌려지는가"를 본다는 것을 적었다([self-improvement-finetune-distill.md](self-improvement-finetune-distill.md)).

## 이 계획이 뒤에 이어진 곳
아래 연결은 이 폴더의 세 기록에는 없다. 뒤에 쓴 공개 문서가 이 계획의 번호·안을 가리키는 곳을 모았다.
- **견고성 넷(가-1·가-2 툴콜 복구, 가-3 편집 되먹임)**: G5 기능 사다리 초안의 L3 "+견고성" 단이 이 번호를 그대로 적는다([../registry/prereg/P-003-ladder-DRAFT.md](../registry/prereg/P-003-ladder-DRAFT.md)). 그 사다리를 개발 묶음에서 잰 것이 창 1 이다([../dev-measure/w1-result.md](../dev-measure/w1-result.md), 개발 점검 · 서술).
- **추론 되돌려 보내기(가-5·나-3)**: 창 3 의 탐색 칸 M-pb 가 `STEWART_REASONING_PASSBACK=current_turn` 으로 이것을 넣었다(판정 없음, [../w3-moderato-effort/design.md](../w3-moderato-effort/design.md)).
- **공개 벤치 어댑터 + 동료 기준선(가-6, 줄기 3, 동료 실행기 결정)**: P-003 초안이 같은 27B 에서 mini-SWE-agent·OpenCode·Pi 기준선과 Terminal-Bench 2.1 파일럿을 다룬다([../registry/prereg/P-003-DRAFT.md](../registry/prereg/P-003-DRAFT.md)). 공개 벤치 쪽 계획·조사·확증은 [../public-bench/](../public-bench/README.md)다.
- **자가발전 E0·E1**: P-003 초안에 E1 어댑터 전후 탐색 칸(Q3·G4)이 있으나, 같은 초안에 E1 돈은 사람 결정으로 거뒀다고 적혀 있다(학습 실험은 맨 뒤로, 따로 결정). 개발 실측의 차례 tag 규칙(`dev-`)은 E1 학습 자료 거르기용이다([../dev-measure/plan.md](../dev-measure/plan.md)).
- 그 밖에 이어진 측정은 [../dev-measure/](../dev-measure/README.md)를 본다.
