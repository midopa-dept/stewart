# 등급 연구

stewart 의 등급(presto·moderato·largo 등)은 같은 모델을 다른 방식으로 쓰는 이름이다. 이 연구는 한 모델(Qwen 계열 27B 4비트) 안에서 **등급마다 도구 묶음·지시문 양·생각 깊이를 하나씩 갈라** 그 등급이 맡는 일로 잰다.

**맨 위 요약**
- 선행 연구에서, 27B 안팎에서 이 셋을 갈라 잰 공개 자료는 우리 조사 범위에서 찾지 못했다([related-work.md](related-work.md)).
- 사전 등록은 **측정 전에** 이 폴더에 올린다. 공개 커밋 시각이 결과보다 앞선다는 것이 증거다.
- 결과는 효과 없음(null)을 포함해 그대로 옮긴다. 확증이 아닌 수치로 "나아졌다"를 말하지 않는다([../protocol.md](../protocol.md)).
