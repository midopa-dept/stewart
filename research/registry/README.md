# 사전 등록·실험 장부

결과를 보기 전에 적은 물음·가설·판정 규칙(사전 등록)과, 실험 장부, 봉인 묶음의 기준과 장부를 모은 곳입니다. 원래 기록의 숫자·sha·규칙·개정 이력을 그대로 옮겼고, 바꾼 것은 [../README.md](../README.md) "공개 범위와 빼는 것"에 적은 낱말뿐입니다.

**맨 위 요약**
- 사전 등록은 P-001–P-003 셋입니다. P-001·P-002 는 등록된 것이고, P-003 은 아직 등록 전입니다.
- 파일 이름에 **DRAFT** 가 붙은 것은 확정 전 초안입니다. 판 이력째 옮겼고, 등록된 것처럼 읽으면 안 됩니다.
- [experiments.tsv](experiments.tsv) 는 실험마다 한 줄인 장부입니다(가설 요약·조건·과제·회차·어림 돈·실제 돈·결과).
- 봉인(보류) 묶음은 **있다는 사실·구성 개수·sha256·사용 횟수·결과만** 공개합니다. 과제 id 목록과 문항 내용은 적지 않습니다.
