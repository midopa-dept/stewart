> 원래 기록: 연구 담당이 총괄에게 올린 공개 벤치 실험 총괄 판 1(2026-11-12 밤). 숫자·규칙은 그대로 옮겼다.
> 꼴: 계획(결과 전). 돈은 모두 [추정]이다.
> 실행 조건: 실행 모델 = Qwen 계열 27B 4비트(계획 당시). 장비 = 빌린 RTX 3090 기계(장당 $0.3/h 로 셈). 과제 실행 쪽 = 로컬 장비의 벤치 VM 또는 빌린 GPU 의 VM 형 인스턴스.

- 돈 셈: **깨끗한 어림**(조사 어림, 3090 장당 $0.3/h) → **현실 어림 × 1.37**(준비·꼬리·낭비) → **상한 × 1.5 더**(창 1 처럼 배수가 1.55 까지 커진 경우). 모두 [추정]이다.

- 단계 1 의 When2Call 같은 벤치는 **에이전트 회차가 아니라 모델 호출**이다. 그래서 평가 대기열(evalq) 밖의 작은 클라이언트 스크립트로, 같은 대여의 다른 차선에서 **나란히** 돈다. 평가 대기열의 대기열 하나 제약을 비켜 간다.
- 단계 2 의 TB 3칸을 벤치 VM(동시 4)에서 돌리면 약 59 과제시간 × 3 ÷ 4 ≈ **44h 벽시계**다. 그동안 GPU 는 대부분 논다. 그래서 TB 는 **빌린 GPU 의 VM 형**(동시 8–16)이 맞고, 벤치 VM 은 smoke·실패 재현용으로 둔다.
- 버리는 것: SWE-bench Verified(27B 86.0, 천장·오염), LiveCodeBench, BFCL 단일 턴, SimpleQA(천장).

## ③ 사람 결정·손이 필요한 것
1. **충전액(단계별)**
   - 단계 1: **$15**(상한 $14.1 + 시험 $1). 빠른 길이라 처음부터 상한까지 넣는다.
   - 단계 2: 단계 1 결과를 본 뒤 **$50 안팎**(현실 $48.7)이다.
   - 지금 남은 개발 실측 몫(창 2 Q2 약 $3.6)은 이것과 따로다.
2. **유료 채점기·사용자 시뮬레이터(Claude·GPT) — 쓰지 않기를 권한다**
   - BrowseComp-Plus: 공식 채점이 로컬 Qwen3-32B 라 유료가 필요 없다. 논문 본표(gpt-4.1 채점)와는 조금 다르다.
   - τ²: 공식 시뮬레이터는 gpt-4.1 이다. 우리 27B 로 대신하면 **공개 숫자와 비교할 수 없다.** 그러나 L2 대 L4 의 **우리 안 비교는 그대로** 된다. 잃는 것은 바깥 대조뿐이다.
   - OverSearchQA: GPT-4o-mini 채점 → 로컬로 대신하면 논문 수치와 못 맞댄다.
   - 실시간 웹 벤치(단계 3)는 유료 채점이 필수라 미뤘다.
   - 바깥 대조가 꼭 필요한 하나만 고르면 τ² 시뮬레이터다(한 벌 수–수십 달러 [추정], 바깥 유료 모델 규칙상 따로 승인).
3. **새 꼴 장비**
   - 빌린 GPU 의 VM 형 대여 시험 약 $1(Docker 확인)이다. 새 제공자·계정은 아니다.
   - 다른 제공자 CPU 서버는 쓰지 않는 쪽으로 권한다(새 계정·망 허용이 든다).
4. **로컬 장비 손**
   - 벤치 VM 설치 한 줄(30–60분)
   - 장비 설정 설치 묶음 한 번: 평가 대기열 호스트 N·차례 상한·FETCH_ALLOW_HOSTS·벤치 VM 역할의 평가 목록·벤치 운영 래퍼
5. 결정하지 않아도 되는 것(총괄이 정함): BrowseComp-Plus 문서 읽기 = (다) FETCH_ALLOW_HOSTS(총괄 결정 11-12, 개발 담당에게 지시함).

## ⑤ 결과를 어디에 쓰나(신뢰 틀)
- 단계 1·2 결과는 "개발 과제 + 바깥 대조" 등급이다. **중간 무게 결정**(실사용 기본의 자기 점검·기억·스킬 끄기, 등급별 생각 기본, 대화 자리·웹 넛지 기본)을 굳히는 데 쓴다.
- 벤치마다 결과 표 머리에 적는 것
  - 학습 오염 가능성: SWE-V 는 버림. TB 2.1·SWE-rebench 최신 창·BrowseComp-Plus 고정 말뭉치는 낮음.
  - 한 번짜리 과제인가: τ² 만 대화형이다.
  - 우리 실사용과의 거리: 영어·위키류.
  - 시간 제한·자원 조건: 같은 모델이 59.5 대 45.5 로 흔들린다. 공개 숫자와는 직접 비교하지 않고, 시간 배수를 고정한 우리 안 비교만 한다.
- 바깥 선례 둘(조사 1)
  - 하니스 셋 × 모델 둘 50과제(arXiv 2607.22585): 통과율 차이 0–8점은 대부분 잡음이고, 해결 과제당 토큰은 40배 차이였다.
  - Qwen3.6-27B SWE-bench Pro: bash 만 28% → 편집 도구 하나를 더하면 50.7%(뼈대의 값).
  - 창 1 그림(mini 71 대 뼈대 89, 그 위는 평평)과 같은 방향이다. 참고 등급이다.
