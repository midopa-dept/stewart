# 선행 연구 — 주제 T1–T5 노벨티 판정과 서지

> 원래 기록: 연구 담당의 노벨티 노트 다섯과 서지 파일(비공개 운영 기록, 2026-11-09–10, 연구 단계 1·2·11). 판정·숫자는 다시 매기지 않고 옮겼다.
> 꼴: 선행 연구 조사(결과 전 기록). 판정은 "우리 주장이 얼마나 새로운가"의 강·중·약이고, 측정 결과가 아니다.
> 실행 조건: 측정 없음. 조사 대상 모델 = Qwen 계열 27B 원본 판(orig)과 같은 모델의 abliteration 판(abl), 4비트(W4A16).
> 공개판에서 바꾼 것: 우리가 쓴 모델 판의 이름·HF 저장소·리비전을 역할 이름으로 바꿨고, 그 판들을 가리키는 서지 항목은 뺐다(abliteration 을 연구 주제로 다룬다는 사실과 남의 논문 인용은 그대로). 세션 결정 표기 → "총괄 결정", 연구 차례 번호 → "연구 단계 N", 범위 표시의 물결표 → en dash.

**맨 위 요약**
- 연구 주제는 다섯이다(T1–T5). 실험 번호(X0-01, X1-01 …)와 주제의 짝은 [../registry/experiments.tsv](../registry/experiments.tsv) 의 topic 칸에 있다.
- 판정: T1 **중**, T2 **중**(X2-02 갈래는 약), T3 **약–중**(관문 닫힘), T4 **약–중**, T5 **중/약**(T2 부속 분석으로만).
- 확인 수준을 칸마다 적었다: 본문(직접)·본문(하위 조사)·초록. 하위 조사 인용 수치는 원문 대조 전이다.
- 가장 큰 판정 바뀜: T1 은 하위 조사가 "강"으로 봤으나, 가중치 차이 감사를 선점한 Hurtado(2607.01854)를 찾아 "중"으로 낮췄다.

## 주제
| 주제 | 한 줄 | 판정 |
|---|---|---|
| T1 | 공개 abliteration 체크포인트의 편집 꼴(층·순위·방향, MTP·비전 미편집, 제3자 양자화 경로)을 가중치로 복원하고 그 결함을 다단계 에이전트 손실에 귀속 | 중 |
| T2 | abliteration 하나만 다른 같은 조리법 4비트 짝으로, 실행기 기법 이득이 손상 특이적인지 검정하고 결함 유형별로 귀속 | 중(X2-02 약) |
| T3 | 새 편집 방법(에이전트 지표 목적·양자화 인지·MTP 함께 편집) — 구성 요소가 다 선점, 공학적 조합 | 약–중, 관문 닫힘 |
| T4 | 보안 과제 단계별(찾기→분류→재현→고치기) + 오탐률 + 비용 벤치, 상용 제품 직접 측정 | 약–중 |
| T5 | 실행기 장치(생각·문맥 압축·되묻기·기억)의 효과 — T2 부속 분석 | 중/약 |
