# 단순화(동작은 그대로)

## 차례
1. 대상을 정한다: 방금 바꾼 것(`git diff`) 또는 사람이 말한 파일·함수.
2. 먼저 시험이 있는지 보고 돌려 둔다 — 없으면 바꾸기 전에 지금 동작을 붙잡는 작은 시험을 만든다.
3. 찾을 것:
   - 같은 일을 하는 코드 두 곳 이상 → 함수 하나로(이미 있는 도우미가 있으면 그것을 쓴다).
   - 쓰이지 않는 변수·인자·분기·주석 처리된 옛 코드.
   - 겹친 조건·깊은 들여쓰기 → 일찍 돌아가기.
   - 고리 안의 되풀이 계산·파일 읽기·네트워크 호출 → 밖으로, 또는 한 번에.
4. 한 번에 한 가지만 바꾸고 시험을 돌린다. 공개된 함수 이름·인자·출력 꼴은 바꾸지 않는다(바꿔야 하면 묻는다).

## 하지 않을 것
- 동작 바꾸기, 취향만의 이름 바꾸기, 관련 없는 파일 고치기.

## 보고 꼴
- 무엇을 왜 줄였나(줄 수 전→후), 시험 결과.
