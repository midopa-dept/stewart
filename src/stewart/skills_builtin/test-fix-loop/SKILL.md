# 시험 돌리고 고치기

## 차례
1. 시험 명령을 찾는다: README·Makefile·pyproject·package.json 의 test 항목. 없으면 사람에게 묻는다.
2. 먼저 한 번 돌려 지금 상태(실패 목록)를 적는다. 오래 걸리면 실패한 시험 하나만 골라 돌린다.
3. 실패 하나씩: 출력의 assert·예외·줄을 읽고, 시험이 기대하는 것과 코드가 하는 것을 비교한다.
4. 구현을 고친다 — 시험을 고쳐 통과시키지 않는다(시험이 틀렸다고 보이면 근거를 들어 사람에게 묻는다).
5. 그 시험을 다시 돌리고, 마지막에 전체를 한 번 더 돌려 다른 것이 깨지지 않았는지 본다.
6. 같은 실패가 두 번 넘게 그대로면 접근을 바꾼다(로그 더 찍기·작은 재현 만들기·error-diagnosis 스킬).

## 보고 꼴
- 처음 실패 수 → 지금 결과, 고친 파일과 까닭, 남은 실패(있으면 까닭).
