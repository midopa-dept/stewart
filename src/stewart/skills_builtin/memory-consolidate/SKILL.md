# 기억 정리 안내

stewart 의 사용자 기억은 세 갈래다: 방침(`policy.md` — 어떻게 일할지), 프로필(`profile.md` — 사용자에 대한 짧은 사실), 자료(`knowledge/` — 고쳐 준 사실·참고). 정리는 사람이 받는 것만 바뀐다.

## 길
- **허브**: 입력 칸에 `/memory` 또는 "기억 정리해 줘". 모델이 세 갈래를 한 번 읽고 제안 카드를 띄운다 — 항목마다 [받기]·[두기], [모두 받기]. 받으면 적용 전 사본을 남기고 되돌리기 한 줄을 보인다.
- **터미널**: `stewart memory consolidate --dry-run`(제안만) → `stewart memory consolidate`(항목마다 묻기) 또는 `--yes`(모두 받기). 되돌리기: `stewart memory consolidate --revert consolidate-<시각>`.
- 직접 고치기: 기억 폴더의 마크다운 파일을 열어 줄을 고치거나 지워도 된다(허브 기억 칸에 자리가 보인다).

## 지킬 것
- 사람이 이 대화에서 정리를 부탁하면, 기억 파일을 도구로 직접 고치지 말고 위 길(`/memory`)을 안내한다 — 사람이 항목별로 보고 받게.
- `stewart dream` 은 다른 층(프로젝트 메모 → 대상 쪽 → MEMORY.md)이다. 사용자 세 갈래는 이 정리로 한다.
