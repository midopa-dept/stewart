# 스킬 만들기

## 꼴
- 폴더 하나 = 스킬 하나: `<스킬 폴더>/<이름>/SKILL.md`(+ 딸린 파일). 이름은 소문자·하이픈.
- SKILL.md 맨 앞:
  ```
  ---
  name: <이름>
  description: <언제 쓰나 + 무엇을 하나 — 200자 안>
  ---
  ```
  그 아래 본문(차례·지킬 것·보고 꼴).
- 자리: 나만 쓰면 사용자 폴더(~/.config/stewart/skills), 이 저장소에서만이면 `.stewart/skills/`. 같은 이름이면 프로젝트 것 > 사용자 것 > 내장.

## description 이 고르기를 정한다
- 모델은 목록의 이름·설명만 보고 고른다. 첫 구절에 **언제 쓰는지**(사람이 하는 말, 놓인 상황)를 적는다: "사람이 '…'라고 하거나, …일 때 쓴다."
- 다른 스킬과 겹치지 않게 경계를 적는다(예: "저장소 전체 감사가 아니라 바뀐 것만").
- 모호한 낱말(돕는다·처리한다)보다 구체적인 동사·대상.

## 본문
- 차례는 번호로, 한 줄씩. 확인 방법과 보고 꼴을 꼭 넣는다. 하지 말 것을 짧게.
- 기기 이름·개인 경로·비밀·내부 번호를 넣지 않는다. 남의 글을 옮기면 라이선스를 확인하고 출처를 적는다.

## 시험
1. 맞는 요청 셋, 비슷하지만 다른 스킬이 맞는 요청 셋을 적는다.
2. 새 세션에서 그 요청을 주고 load_skill 이 맞게 불리는지 본다. 틀리면 description 을 고친다.
