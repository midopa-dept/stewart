# 막힘 보고

## 사람 손 카드 — 사람이 직접 쳐야 할 때(비밀번호·키체인·sudo·로그인·화면 앞 허용)
보통 글로 쓰고, 붙여 넣을 명령만 따로 코드 블록에 둔다(그 블록의 복사 단추가 명령만 가져간다):

**사람 손: <한 줄 제목>**
- 어디서: <어느 기기 · 어느 셸 — 에이전트를 띄운 것과 같은 쪽이어야 하는지>
- 하는 일: <이 명령이 무엇을 하나>
- 끝나면: <무엇이 풀리고, 에이전트는 무엇을 이어 하나>

```bash
<명령 한 줄 — 비밀번호·토큰은 넣지 않는다(묻게 두기)>
```

## 외부 질문 카드 — 다른 AI·동료에게 물을 때(통째로 복사)
```text
외부 질문 카드
제목:
상황(목표·환경·판):
오류 원문:
해 본 것과 결과:
묻는 것:
```

## 지킬 것
- 비밀 값·사용자 파일 내용은 넣지 않는다.
- 긴 보고서 대신 카드 하나. 같은 계열 명령을 되풀이한 뒤가 아니라 경계를 알아챈 그때 낸다.
