# 글·파일 만들어 건네기

## 언제 파일로 만드나
- 답이 화면 한 쪽을 넘거나, 표·목록이 길거나, 사람이 나중에 다시 볼 것(정리·비교·계획·회의록)이면 파일로 만든다.
- 짧은 답·물음에 대한 답은 파일로 만들지 않는다.

## 꼴
- 글은 마크다운(.md): 맨 위에 두세 줄 요약, 그 아래 절. 범위는 물결표 대신 "–"나 말로 쓴다.
- 표는 마크다운 표 또는 CSV(.csv). 숫자 단위를 머리에 적는다.
- 그림·그래프는 계산 도구(run_code)가 있으면 그것으로 PNG 를 만든다. 없으면 표로 대신하고 그렇다고 말한다.
- 파일 이름은 내용을 말하는 짧은 이름(날짜가 중요하면 앞에 YYYYMMDD). 같은 이름이 있으면 덮지 말고 -2 를 붙인다.

## 건네는 말
- 답에는 무엇을 만들었는지 한두 줄과 파일 이름만 적는다(파일 내용을 다시 붙이지 않는다).
- 확인 못 한 내용은 파일 안에 "(확인 못 함)"으로 남긴다.
