# 띄워서 확인하기

## 차례
1. 어떻게 띄우는지 찾는다: README·Makefile·package.json scripts·pyproject 의 scripts·Procfile·docker compose.
2. 명령줄 도구면: 대표 입력 하나로 돌리고 출력·종료 코드를 본다. 잘못된 입력 하나도 넣어 본다.
3. 서버면: 백그라운드로 띄우고(run_shell 의 백그라운드·shell_output 으로 기록 보기), 준비 줄(listening·ready)을 기다린 뒤 `curl` 로 주요 길 하나·오류 길 하나를 부른다. 끝나면 끈다.
4. 화면(웹)이면: 띄운 주소를 알려 주고, 화면 확인이 필요한 것은 사람에게 무엇을 볼지 목록으로 넘긴다(브라우저를 못 쓰는 자리면).
5. 바꾼 동작이 실제로 보였는지, 바뀌지 말아야 할 것이 그대로인지 둘 다 본다.

## 지킬 것
- 오래 도는 것은 시간 상한을 둔다. 띄운 것은 끝에 끈다(남기지 않는다).
- 바깥 서비스·돈이 드는 호출·되돌릴 수 없는 동작(메일 보내기·배포)은 사람에게 묻는다.

## 보고 꼴
- 띄운 명령 / 확인한 것과 결과(출력 일부) / 못 본 것.
