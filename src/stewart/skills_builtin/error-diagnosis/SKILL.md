# 오류 진단

## 차례
1. 오류 원문을 그대로 옮겨 적는다(코드·메시지·어느 명령에서).
2. 뜻부터 찾는다 — 원인을 짐작하기 전에:
   - 명령 도움말: `<명령> --help`, `man <명령>`
   - 운영체제 오류 번호: `python3 -c 'import os; print(os.strerror(N))'`
   - macOS 보안 프레임워크 코드(음수 다섯 자리 등): `security error <코드>`
   - 웹 도구가 있으면 오류 문구를 따옴표로 묶어 검색, 공식 문서·이슈를 원문으로 연다.
3. 가설을 둘셋 세우고, 가설마다 "그것을 가르는 싼 확인 하나"를 적는다(설정 한 줄 읽기, 판 확인, 다른 입력으로 한 번).
4. 확인을 돌리고 나서야 원인이라고 쓴다. 돌리지 않은 것은 "추측"이라고 적는다.
5. 같은 오류를 내는 같은 계열 명령을 세 번 넘게 돌리지 않는다 — 새 정보를 주는 다른 확인으로 바꾼다.
6. 비밀번호·키체인·sudo·로그인처럼 사람만 풀 수 있는 경계면 멈추고 사람 손 카드로 넘긴다(blocked-report 스킬).
