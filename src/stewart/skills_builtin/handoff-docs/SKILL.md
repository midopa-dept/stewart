# 인계 문서 쓰기

## 언제
- 긴 일을 멈추거나 다른 사람·세션에 넘길 때, 큰 조각이 끝났을 때.

## 담을 것(짧게, 확인된 것만)
1. 지금 상태: 어느 가지·커밋, 원격에 올렸는지, 미커밋 변경이 있으면 무엇과 까닭.
2. 한 것: 바꾼 파일과 결과, 돌린 확인(시험 명령과 결과 수).
3. 남은 것: 다음 할 일 차례대로, 각 끝의 기준.
4. 막힌 것·결정 기다림: 누구의 결정인지, 고를 안과 권장.
5. 함정: 해 봤는데 안 된 길과 까닭(같은 실수를 되풀이하지 않게).
6. 다시 해 보는 법: 시험·실행 명령을 그대로 붙일 수 있게.

## 하지 않을 것
- 짐작을 사실처럼 쓰기, 비밀 값 넣기, 대화 전체를 옮겨 적기.
