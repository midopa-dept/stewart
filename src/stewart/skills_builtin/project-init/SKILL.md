# 프로젝트 안내 파일 만들기(init)

## 목적
- 다음에 이 저장소에서 일할 에이전트(와 사람)가 바로 알아야 할 것을 한 장에. 길게 쓰지 않는다(한두 화면).

## 차례
1. 이미 있는지 본다: AGENTS.md·STEWART.md·CLAUDE.md·README. 있으면 고칠 곳만 제안한다(덮어쓰지 않는다).
2. 읽는다: README, 빌드·시험 설정(pyproject·package.json·Makefile·CI 파일), 맨 위 폴더 구조, 진입점 파일 몇 개.
3. 돌려 본다(가능하면): 시험 명령·빌드 명령이 실제로 되는지 한 번.
4. 초안에 담을 것:
   - 한 줄 소개
   - 자주 쓰는 명령(설치·빌드·시험·한 시험만 돌리기·린트) — 돌려 본 것만, 못 돌린 것은 표시
   - 구조: 큰 폴더와 하는 일, 핵심 모듈 몇 개
   - 규칙: 코드 꼴, 고치면 안 되는 것, 생성 파일, 비밀 다루기
   - 함정: 처음 오는 사람이 걸리는 것
5. 파일 이름: stewart 전용이면 STEWART.md, 여러 도구가 같이 쓰면 AGENTS.md. 쓰기 전에 사람에게 초안을 보이고 어느 이름으로 둘지 묻는다.

## 하지 않을 것
- README 를 옮겨 적기, 짐작한 명령 적기, 비밀·개인 경로 넣기.
