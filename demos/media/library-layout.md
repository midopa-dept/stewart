# 서고 구조 (예시 미디어 서버의 폴더 규칙)

목적지는 서고 최상위 기준 상대 폴더로 쓴다. 최상위는 아래 11개뿐이다.

| 최상위 | 하위 규칙 | 예(형식) |
|---|---|---|
| Anime | <제목> (<연도>)/Season <NN>/ — 스페셜은 Season 00, 부록(해설·특전 영상 등)은 <제목> (<연도>)/extras/ | Anime/<제목> (2009)/Season 01 |
| Shows | 드라마 등 실사 시리즈. Anime와 같은 규칙 | Shows/<제목> (2018)/Season 01 |
| Movies | <제목> (<연도>)/ | Movies/<제목> (2015) |
| Variety | <그룹>/<프로그램>/ (프로그램 부록은 그 아래 extras/) | Variety/<그룹>/<프로그램> |
| Concerts | <그룹>/ 아래 평평하게(음악방송·시상식 무대 등) | Concerts/<그룹> |
| Clips | <그룹>/ 아래 평평하게(짧은 영상·특집 컷 등) | Clips/<그룹> |
| MusicVideos | <그룹>/ 아래 평평하게 | MusicVideos/<그룹> |
| Music | <가수>/<앨범>/ 기본. 규칙이 통일되지 않음: 낱곡 모음 `일반`·`일반_N`, `[날짜] 앨범` 형식 섞임, 디스크 하위 폴더(Disc 1·CD1), 부클릿 스캔은 앨범 아래 Scans/ 또는 BK/ | Music/<가수>/<앨범> |
| Photos | <그룹>/<멤버>/… 또는 사진집 폴더 | Photos/<그룹>/<멤버> |
| Comics | <작품>/<권>/ | Comics/<작품>/<권> |
| Archives | 압축 파일·게임 OST 등 | Archives/Game/<게임 OST> |

특수 목적지(서고 밖, 사람이 처리):
- `_review/` — 이름만으로 판단할 수 없음
- `_incomplete/` — 받는 중이거나 분할 압축(.part, .partN.rar 등)
- `_junk/` — 시스템 파일(Thumbs.db, desktop.ini, .DS_Store 등). 지우지 않고 모으기만 한다.

판단 요령:
- 제목·연도·시즌을 이름에서 알 수 있어야 폴더 이름을 정확히 쓸 수 있다. 원본 이름(로마자 제목 등)만 있으면 서고의 한국어 제목을 알 수 없으니 확실한 것만 쓴다.
- 앨범 폴더를 알 수 없는 음악 낱곡은 `Music/` 아래 어디인지 정할 수 없다. 낱곡 모음(`Music/일반`)은 "가수 - 곡" 형식의 낱곡에 쓴다.
- 그룹 이름은 이름에 그룹·멤버·프로그램이 드러날 때만 쓴다.
